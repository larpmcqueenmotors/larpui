# Third-party icon notices

The vehicle warning icons in this folder are adapted from
[Material Design Icons](https://pictogrammers.com/library/mdi/) by
[Pictogrammers](https://pictogrammers.com/), distributed in
[`@mdi/svg` 7.4.47](https://www.npmjs.com/package/@mdi/svg).

The icons are used under the
[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).
Their SVG wrappers were normalized to use `currentColor`, accessible titles
were added, and path number formatting was compacted. The path geometry is
otherwise unchanged.

- `oil.svg` — `oil.svg`
- `seatbelt.svg` — `seatbelt.svg`
- `service.svg` — `wrench.svg`
- `steering.svg` — `steering.svg`
- `temperature.svg` — `thermometer-alert.svg`
- `tire.svg` — `car-tire-alert.svg`
- `traction.svg` — `car-traction-control.svg`

The severity icons (`caution`, `warning`, `danger`, `critical`, `stop`, and
`restricted`) are original LARP UI artwork and are not part of MDI.
